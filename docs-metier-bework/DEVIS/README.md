# Devis / DPGF — Contrôles

## Comparaisons systématiques

| Source A | Source B | Contrôle |
|----------|----------|----------|
| CCTP | Devis | Prestations comprises / exclues |
| Devis | DPGF | Quantités, unités, libellés |
| Devis | FT | Produits nominatifs |
| Devis | Notice pose | Mise en œuvre, accessoires |

## Signaux d’alerte

- Ligne devis sans équivalent CCTP  
- Produit FT différent du CCTP  
- Accessoires (liteaux, pare-pluie, ventilation) absents du devis  
- Sous-traitance non déclarée DC4
