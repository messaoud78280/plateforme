# Convention DOE informatique (type NEOTOA / Helios)

Source type : annexe CCTP « convention informatique DOE » + CCAP art. 40.

## Règles générales

- Livraison sur **DVD ou clé USB**
- **Dossier racine unique** — pas de sous-dossiers imbriqués hors convention
- Formats acceptés : **PDF ou DWG** uniquement (autres formats refusés)

## Nommage type

`DOE-<Corps d'état>-<Nom entreprise>/`  
Fichiers : `<Entreprise>-<Bat|PAV>-<entrée>-<Niveau>-<Type>-<dénomination>.pdf`

## Fichiers obligatoires par lot (extraits CCAP Helios OP000474)

| Lot | Documents typiques |
|-----|-------------------|
| Gros œuvre | Plans BA, récolement EU-EP-drainage, enduits (garantie + FT) |
| Charpente | Plans + réservations, certificat traitement bois |
| Couverture | Garantie ardoises, liste prestations chantier |
| Étanchéité | Certificat procédé, liste prestations |
| Menuiseries | Plans réservations, quincaillerie, AT/CSTB, liste prestations |
| Plomberie | Réservations, types appareils, COPREC, récolement, liste matériaux |
| Électricité | **Consuel** (remise mains propres NEOTOA), récolement, COPREC, liste matériaux |
| Chauffage | Consuel ou Qualigaz, COPREC, récolement, liste matériaux |

Un exemplaire DOE est remis au **coordonnateur SPS** pour cohérence avec le **DIUO**.

## Pénalité retard DOE (CCAP Helios)

**Fait constaté** : pénalité possible si DOE incomplet — **1/100 du montant marché HT par jour calendaire** (art. 19 CCAP, renvoi art. 40).

## Vigilance conducteur

- Préparer le nommage **dès le démarrage** (pas en fin de chantier)
- Une fiche FT par produit réellement posé
- COPREC et essais : dates MOE bloquées tôt
- Consuel : circuit papier séparé de la GED
