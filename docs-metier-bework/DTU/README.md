# DTU — Usage BeWork

- Citer un **DTU précis** uniquement si présent dans le CCTP, la FT ou une pièce du dossier.
- Sinon : « conforme aux règles de l’art » ou « DTU applicable — **à vérifier** avec le MOE ».
- Ne jamais inventer de numéro de DTU pour « faire joli ».

Le skill CCTP propose des rappels **indicatifs** par famille d’ouvrage ; validation humaine obligatoire.
