# Fiches techniques — Lecture métier

## À extraire d’une FT

- Produit, fabricant, référence  
- Support compatible / incompatible  
- Performances (feu, acoustique, thermique — si chantier concerné)  
- Accessoires obligatoires  
- Conditions de pose (température, jeux, fixation)  
- Garanties et documents DOE associés  

## Cohérence

Comparer **FT + notice de pose + CCTP + devis** avant commande et avant réception.

Exemples terrain : `../EXEMPLES-CHANTIER/`.
