# Risques si ce n’est pas maîtrisé

| Risque | Conséquence |
|--------|-------------|
| DPGF / devis non alignés CCTP | Refus situation Ediflex, litige prix |
| Retard planning vs 1/2000/j | Pénalités rapides sur grosses enveloppes |
| DOE incomplet ou mal nommé | **1/100 marché HT / jour** + blocage réception |
| Insertion non suivie | Non-conformité marché, retenues |
| Index BT mal déclarés | Écart actualisation, contestation MOA |
| Consuel non remis comme prévu | Blocage réception lot électricité |
